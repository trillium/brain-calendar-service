# RFC 5546 resolution

## What it is
A total order over a pair of calendar occurrences: identity (UID + RECURRENCE-ID),
then SEQUENCE, then DTSTAMP, then a deterministic canonical tie-break. Beads is
the ORGANIZER, so Beads assigns SEQUENCE and external calendars are clients of it.

## How to drive it
```sh
pnpm run test -- src/domain/rfc5546 --run
pnpm run test -- src/domain/rfc5546/properties --run
```

## What it should produce
Both halves green, and `evidence/stage-02/decision-table.md` regenerated with a
totals block: pairs exercised, resolutions that conflicted, resolutions that
retained both sides, and **resolutions with no reason — which must be 0**.

## What breaks if it breaks
Everything downstream. Conflict resolution is the reason the sync engine can be
authoritative at all; a resolver that returns "unknown" for some pair means
silent divergence between two calendars that both believe they won.
